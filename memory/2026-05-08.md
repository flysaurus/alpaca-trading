### Critical Bug Fix: Fake Portfolio History (8bd81c2)
- **Issue**: Portfolio value chart was completely fabricated using `Math.sin(date.getTime())` — no real API data
- **Impact**: Numbers shifted every few seconds as `new Date()` changed, creating "alive" bars
- **Fix**:
  1. Added `getPortfolioHistory()` to `src/lib/alpaca.ts` using Alpaca SDK's real `GET /v2/account/portfolio/history`
  2. Created `/api/portfolio/history/route.ts` server-side endpoint
  3. Rewrote `PerformanceCharts.tsx` — `PerformanceCard` fetches real data via `useEffect` on `/api/portfolio/history?period=...`
  4. Removed all fake data generators from `page.tsx` and `portfolioAnalytics.ts`
- **Result**: Chart now shows real equity values and real daily P&L from Alpaca

### Key Lesson
- When building financial dashboards, ALWAYS verify data comes from real API endpoints, not mock/fallback generators. Sine waves look convincing but are fiction.
