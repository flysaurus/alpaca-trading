**4. Health Auto Export Webhook Parsing**

**6. Duplicate Prevention**
- Memory-level dedup via `makeDedupKey()` using minute-granularity
- Supabase-level: `ALTER TABLE workouts ADD CONSTRAINT unique_workout_per_day UNIQUE (date, workout_type)`
- Required deduplicating existing data first with `DELETE FROM workouts WHERE id NOT IN (SELECT DISTINCT ON...)`

**7. Date Parser Fix**
- **Bug:** `new Date("2026-05-02 15:52:38 -0400")` silently produces today's date instead of erroring
- **Fix:** Use explicit regex for HAE format, calculate UTC offset manually, return `new Date(localMs - offsetMs).toISOString()`
- Extract year from first capture group, not `match[0].slice(0,4)` which was broken

### Lessons Learned
1. **Never use `.catch(() => {})`** on external API calls — silently swallows all failures
2. **Vercel serverless = stateless** — in-memory stores vanish on every deploy/cold start
3. **`new Date(string)` is dangerously permissive** — it "succeeds" with garbage input, producing wrong dates silently
4. **HAE v2 schema** — uses `start`/`end` not `startDate`/`endDate`, nested `{qty, units}` objects, space-separated datetime
5. **Always await async persistence** in webhooks — fire-and-forget loses data on serverless
