## Alpaca Trading App — Round 2 Fixes (Em)
**Date:** 2026-05-07 evening session

### Issues Fixed

1. **Watchlist on wrong tabs** — `WatchlistWidget` + `RiskThresholdSelector` were placed before the tab conditional, so they showed on ALL tabs. **Fix:** Moved them inside `{activeTab === 'dashboard'}` block in `src/app/page.tsx`.

2. **No Telegram fill notifications** — Alpaca's API only sends status change via webhooks (not push). The app wasn't polling for fills after initial "order accepted" notification. **Fix:** Built `src/lib/orderFillNotifier.ts` — lightweight client-side poller that hits `/api/orders` every 20s, tracks already-notified IDs in localStorage, and fires `POST /api/alerts/telegram-fill` which sends formatted Telegram messages with filled qty, avg price, total value, and ET timestamp. Wired into `page.tsx` via `useEffect`.

3. **`/advisor` page crashed with "This page couldn't load"** — **Root cause:** Next.js SSR hydration mismatch. `RiskBadge` component called `useState(getStoredRisk())` where `getStoredRisk()` accessed `localStorage` during browser hydration. Server rendered `'moderate'` but client tried to read localStorage → fatal mismatch. Also: `getStoredRisk()` called again in the empty-state conditional display.
   **Fix:** Changed `RiskBadge` to initialize with `'moderate'` and read localStorage inside `useEffect`. Removed the direct `getStoredRisk()` call from the empty-state section.

4. **"4 Active strategies" / "68% success rate" — meaningless hardcoded stats** — Replaced static grid with real strategy definitions: DCA, Rebalance, Momentum, Mean Reversion. Each shows name, description, and algorithm. Rows link to `/strategies`. Status shows "Available" until enabled.

5. **AI news not clickable** — Added click-to-expand inline detail view with summary, sentiment badge, related symbol, external article link, and a back button.

6. **AI Trading Advisor card too wide** — Replaced full-width centered block with compact flex-row card: icon + description + algorithm tags (RSI, MACD, Sentiment, Insider Flow) + Launch button. Takes ~60% less vertical space.

### Files Created
